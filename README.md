# Pranay Bansilal Patil — Portfolio

Personal portfolio website for Pranay Bansilal Patil (AI/ML, Data Science & Analytics Engineer), built in a Limestone & Terracotta architectural theme.

## Edit portfolio content

Open [Portfolio Studio](https://pranayportfolio-indol.vercel.app/studio) and sign in with the authorized Supabase portfolio account. Select a section to edit its content and see the changes in the preview. **Save draft** keeps a private copy. **Publish changes** updates the public site the next time it loads. Text and image updates do not require a GitHub commit or a Vercel deployment.

The studio uses the existing `pranay-portfolio` Supabase project. Public visitors can read published content. Supabase access policies restrict editing and image uploads to the portfolio editor account.

## Deploy to Vercel

1. Push this folder to the `Pranay_Portfolio` GitHub repository.
2. Go to [vercel.com/new](https://vercel.com/new), import `Pranay_Portfolio`, and click **Deploy** (zero build step required).
